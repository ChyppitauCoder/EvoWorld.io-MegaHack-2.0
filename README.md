<h1>How to install & use</h1>

- 1st step. Download <a href="https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=en">tampermonkey</a>
- 2nd step. Download code as a zip archive.
- 3rd step. Unzip code into any folder.
- 4th step. Open tampermonkey's control panel.
- 5th step. Move "main.js" file in tampermonkey control panel.
- 6th step. Click "Install/Reinstall/Update" button.
- 7th step. Open the game.
- 8th step. Tampermonkey will ask you: "A user script wants to access a third-party resource." press "allow for all time" (this is a safe action, because hack has open source code and you can check safety yourself).
- 9th step. Agree with ban risks.
- 10th step. Press tab or F9 in game.
- 11th step. Enjoy!
